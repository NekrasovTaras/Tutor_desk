# TutorDesk 0.2

24 октября 2026 года.

Преподаватель может изменить название, условие и срок домашнего задания, пока ученик не отправил ответ. Откройте задание со статусом «К выполнению» и нажмите «Изменить задание». После отправки ответа изменение запрещено на сервере, в том числе из уже открытой формы. Ученик и связанное занятие сохраняются.

Кнопка «Отмена» явно имеет тип button: закрытие формы не должно отправлять изменения. Часть лозунгов в интерфейсе заменена пояснениями по работе с кабинетом.

## Проверки

- Windows, Python 3.14, SQLite: 31 тест прошёл, включая 10 новых сценариев редактирования.
- `node --check app/static/app.js` и `python -m pip check`: успешно.
- В работающем браузере выполнены вход преподавателя, открытие задания, редактирование названия и сохранение. Новое название появилось в списке.
- Схема базы данных не менялась.
- Сохраняется предупреждение Starlette о будущем отказе от httpx в TestClient.

## Запуск в PyCharm

Используйте существующее окружение `.venv`, откройте `run.py` и нажмите Run. Кабинет доступен по адресу http://127.0.0.1:8000.

Для создания учебных данных: `python -X utf8 -m app.seed`. Флаг UTF-8 предотвращает ошибку вывода кириллицы в некоторых консолях Windows. Реальные данные и `.env` в Git не включаются.
