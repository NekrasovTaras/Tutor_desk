# TutorDesk: план совместной разработки

## 0.1 — текущая поставка

Рабочее ядро: аккаунты, ученики, расписание, ДЗ, роли, тесты. Сначала запустить и проверить обе роли локально.

## Следующие учебные итерации

1. **Понять один полный запрос.** `POST /api/students`: форма → Pydantic → проверка роли → User + Student → транзакция → JSON → интерфейс. Самостоятельно добавить необязательное поле и миграцию.
2. **Улучшить ДЗ.** Редактирование до отправки ответа, возврат на доработку. Описать переходы статусов и проверить запрещённые переходы тестами.
3. **Укрепить расписание.** Повторяющиеся уроки, исключения для одной даты, напоминания. Сначала сформулировать правила переноса всей серии.
4. **Перейти на PostgreSQL.** Прогнать интеграционные тесты на реальной PostgreSQL, проверить параллельные запросы и изучить блокировки.
5. **Добавить фоновые задачи.** Напоминание о занятии через выбранный канал; очередь, повторные попытки и защита от повторной отправки.
6. **Подготовить публикацию.** Восстановление пароля, HTTPS, секреты, резервные копии, логи, проверка восстановления БД.
7. **Оформить портфолио.** Скриншоты собственного демо, короткое видео, понятный README и описание двух-трёх инженерных решений с тестами.

Не расширять все направления одновременно. Каждая итерация заканчивается работающим пользовательским сценарием и осмысленным коммитом.
